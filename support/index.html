1. はじめに

JShell GUI は、HTML・CSS・JavaScript だけで作られた「ブラウザの中の OS」です。インストールは不要で、PC・iPad・iPhone・Android の新しめのブラウザで動きます。

JShell GUI を開く
インターネット接続について：アイコンは Google の Material Icons を使うため、読み込めないとアイコンが英単語で表示されます（ウィンドウ右上の３つのボタンだけは – □ × に自動で切り替わります）。

はじめて起動したとき

  1. ページを開くと、約 1 秒の起動画面が表示されます。
  2. 「アカウントの作成」画面が出ます。ユーザー名（英数字と . _ - のみ・24 文字まで）を入力します。
  3. パスワードは任意です。空欄のままにするとパスワードなしで使えます（あとから設定アプリで変更できます）。
  4. 「作成」を押すとデスクトップが表示されます。ユーザー名のホームフォルダー（Users/あなたの名前）と、Desktop・Documents・Downloads フォルダーが自動で作られます。

２回目以降

起動後にログイン画面が表示されるので、パスワードを入力して「サインイン」を押します（パスワードを設定していない場合は「サインイン」だけで入れます）。

文字だけの JShell から開く

文字だけの JShell (CUI) では、start -g と入力すると新しいタブでこの GUI が開きます。

デスクトップ

左上にごみ箱のアイコンだけが置かれています。ダブルクリック（タップ）で開きます。何もない所を右クリックすると「個人用設定」と「シェル」のメニューが出ます。

タスクバー（画面の下）

場所はたらき

フォルダー・ターミナル・歯車エクスプローラー・シェル・設定をすぐに開けます。
区切り線のあとのボタン開いているウィンドウです。押すと前面に出ます。前面のウィンドウをもう一度押すと最小化、最小化中なら元に戻ります。
右端時刻と日付です。

スタートメニュー

  • アプリ：エクスプローラー／シェル／メモ帳／設定／レジストリ エディター／ごみ箱
  • サインアウト：ログイン画面に戻ります。
  • 再起動：起動画面からやり直します。
  • UEFI ファームウェア設定：BIOS 画面に入ります（10 章）。
  • 回復環境：回復環境に入ります（12 章）。
  • シャットダウン：画面が消えます。クリック（タップ）すると電源が入ります。

4. シェル（文字で操作するアプリ）

コマンドを打って操作するアプリです。画面の下の 名前@jshell:~> のあとにコマンドを入力して Enter を押します。↑ ↓ で入力した履歴をたどれます。大文字・小文字は区別されません。

clear画面をきれいにします。
echo 文字文字をそのまま表示します。
echo こんにちは

cd Documents　cd ..　cd ~

cat ファイルテキストファイルの中身を表示します。

touch 名前空のファイルを作ります。

5. エクスプローラー（ファイル管理）

左側に、フォルダー全体がツリーで表示されます。├── や └── の線でどのフォルダーの中にあるかが分かります。右側には、いま選んでいるフォルダーの中身が並びます。

C:/
├── Users
│   └── maito
│       ├── Desktop
│       ├── Documents
│       └── Downloads
└── Windows

基本の操作

  • フォルダーを開く：左のツリーのフォルダーをクリック（開閉もできます）。右の一覧ではダブルクリック（ダブルタップ）します。
  • ファイルを開く：ツリーでクリック、または右の一覧でダブルクリックするとメモ帳で開きます。
  • ひとつ上へ：上部の矢印（↑）ボタンです。上のアドレス欄は現在の場所の表示用で、入力はできません。
  • 新しいフォルダー／ファイル：上部のフォルダー＋ボタン／ファイル＋ボタンを押し、名前を入力します（/ と \ は使えません）。
  • 削除：右の一覧で項目をクリックして選び、ごみ箱ボタンを押します。ごみ箱に移動するだけなので、あとで戻せます。

ツリーの一番下の「ごみ箱」をクリックすると、ごみ箱の中身が表示されます。

6. メモ帳

テキストファイルを編集するアプリです。エクスプローラーでファイルを開くと起動します。スタートメニューから開くと、新規の白紙になります。

  • 保存：上部の「保存」ボタンを押します。
  • 新規の場合は、ファイル名を聞かれます。入力すると Documents フォルダーに保存されます。
  • 保存しないで閉じると、編集した内容は失われます。

7. 設定

左のメニューから項目を選びます。設定アプリは同時に１つだけ開けます。

項目できること
個人用設定テーマ（ダーク／ライト）、アクセントカラー（６色）、壁紙の色（６色）を変えられます。選ぶとすぐ反映されます。
アカウントパスワードの変更・削除ができます。新しいパスワードを入れて「変更」を押します。
システム情報ブラウザの情報、画面の大きさ、CPU の数、保存されているデータの大きさを確認できます。「初期化」を押すと、すべてのデータを削除して最初の状態に戻します（確認あり・元に戻せません）。
ブートとUEFI「UEFI ファームウェア設定へ再起動」と「回復環境へ再起動」ができます。

設定した内容はレジストリに保存されます（テーマ・アクセント・壁紙は HKEY_CURRENT_USER\Software\JShell）。

8. レジストリ エディター

OS の設定値を直接見たり書き換えたりするアプリです。左がキー（フォルダーのようなもの）のツリー、右がそのキーに入っている値の一覧です。

  • 値を編集：右の一覧で値をクリックすると入力欄が出ます。
  • 値を追加：上部の「値」ボタン。キーを追加：「キー」ボタン（名前に / と \ は使えません）。
  • キーを削除：「キー削除」ボタン（一番上の HKEY_ で始まるキーは削除できません）。
⚠ 正しくない値を保存すると、ブルースクリーンになります。 次の値には決まりがあり、守られていないと即座にブルースクリーン（11 章）が表示されます。大文字・小文字も区別され、Dark は誤りです。値を削除した場合も同じです。
場所（キー）値の名前正しい値初期値
HKEY_CURRENT_USER\Software\JShellThemedark か lightdark
同上Accent色コード（#0078d4 のような #＋3 桁または 6 桁の 16 進数）#0078d4
同上Wallpaper色コード#0b3d91
HKEY_LOCAL_MACHINE\SYSTEM\BootBootDelay0〜60000 の数字（ミリ秒）1200
同上SecureBootEnabled か DisabledEnabled
同上FastBootEnabled か DisabledDisabled

これ以外のキーや値は自由に追加・編集できます。誤った値は右の一覧で赤く表示されます。

9. ごみ箱

エクスプローラーやシェルで削除したものがここに入ります。デスクトップのアイコンか、スタートメニュー、エクスプローラーのツリーから開けます。

  • 元に戻す：項目を選んで「復元」ボタン。元の場所に戻ります（元のフォルダーが無いときはホームに戻ります）。
  • 完全に削除：項目を選んで削除ボタン（元に戻せません）。
  • 空にする：「ごみ箱を空にする」ボタンで全部を完全に削除します。

10. UEFI（BIOS）

OS が起動する前の設定画面です。青い画面に灰色の枠で表示されます。

入りかた

  • 起動画面が出ている間（初期設定では約 1.2 秒）に、Enter を 3 回続けて押します。
  • または F2、Delete、Esc のどれかを押します。
  • キーボードのない端末では、起動画面を 3 回続けてタップします。
  • スタートメニュー「UEFI ファームウェア設定」、設定アプリ、回復環境からも入れます。
間に合わないときは、いったん UEFI に入って Boot Delay（待ち時間）を長くしてください。

画面の項目

タブ内容
Mainファームウェア、CPU の数、メモリの目安、画面サイズ、ユーザー名を表示します（見るだけ）。
BootBoot Delay（0 / 300 / 600 / 1200 / 3000 / 5000 ms から順に切り替え）と、Fast Boot（有効だと待ち時間が約 0.3 秒に短縮）。
SecuritySecure Boot の切り替え。仮想の項目で、動作には影響しません。
Exit保存して終了／破棄して終了。

キー操作

キー動作
← →タブを切り替える
↑ ↓項目を選ぶ
Enter / Space値を変える
F10保存して終了
Esc変更を破棄して終了

マウスやタップでも操作できます。終了すると OS が再起動します。設定は HKEY_LOCAL_MACHINE\SYSTEM\Boot に保存されます。UEFI を開いた直後の約 0.6 秒間は、Enter の連打で値が変わらないように Enter を無視します。

11. ブルースクリーン

重大なエラーが起きると、青い画面に :( と進行状況が表示されます。数字が 0% から 100% まで進み、100% になると「再起動します...」と表示されて自動で再起動します。操作は必要ありません。

表示される原因（停止コード）

停止コード原因
CRITICAL_REGISTRY_VALUEレジストリに正しくない値を保存した、または必要な値を削除した（8 章）。
MANUALLY_INITIATED_CRASHシェルの crash コマンドを実行した。
SYSTEM_THREAD_EXCEPTION_NOT_HANDLEDプログラムの途中でエラー（例外）が発生した。
KERNEL_SECURITY_CHECK_FAILURE処理の失敗が処理されないまま残った。

「失敗した内容」には、どの値やファイルが原因かが表示されます。再起動後、ふつうは通常どおり起動します。ただし、不正なレジストリ値が残ったまま、またはブルースクリーンが 2 回続いた場合は、自動的に回復環境が開きます。

12. 回復環境

OS が正常に起動しないときに使う、Windows の回復環境（WinRE）に似た修復用の画面です。

開きかた

  • 自動：不正なレジストリ値があるまま起動したとき、またはブルースクリーンが 2 回続いたとき。「自動修復を準備しています」→「PC を診断中...」のあと、「PC が正常に起動しませんでした」と表示されます。ここで詳細オプションを選びます。
  • 手動：スタートメニューの「回復環境」、設定アプリの「回復環境へ再起動」、シェルの recovery。

操作は ↑↓←→（選ぶ）、Enter（決定）、Esc（戻る）、またはマウス・タップです。

メニューの構成と中身

メニュー内容
続行終了して OS を起動し直します。問題が直っていなければ、また自動修復になります。
デバイスの使用（未対応）「利用できるデバイスが見つかりません」と表示されます。
トラブルシューティング → このPCを初期状態に戻すすべてのデータを削除して最初の状態に戻します（確認あり）。
詳細オプション → スタートアップ修復正しくないレジストリ値を、初期値にまとめて戻します。まずこれを試してください。
詳細オプション → システムの復元最後に正常に起動できたときのレジストリの状態に戻します。
詳細オプション → UEFI ファームウェアの設定UEFI 画面を開きます。
詳細オプション → コマンド プロンプト修復用の小さなコンソールです。help reg（不正な値の一覧）repair restore exit が使えます。
スタートアップ設定／更新プログラムのアンインストール（未対応）「利用できません」と表示されます。
PC の電源を切るシャットダウンします。
困ったときの順番：① スタートアップ修復 → ② システムの復元 → ③ このPCを初期状態に戻す（最後の手段）。

13. データの保存とセキュリティ

  • ファイル、設定、パスワードは、お使いのブラウザの中（localStorage）に保存されます。サーバーには送信されません。
  • 保存されるのは、そのブラウザ・その端末だけです。別の端末や別のブラウザとは共有されません。プライベートブラウズでは、閉じると消えることがあります。
  • ブラウザの「サイトデータの削除」や「履歴の消去」を行うと、データがすべて消えます。大切なものは別に控えてください。
  • 保存できる量はブラウザの上限（おおよそ 5MB）までです。
  • 文字だけの JShell (CUI) とは、データは別々です。
パスワードについて：このパスワードは「ふんいき」のための機能で、本物のセキュリティではありません。ブラウザの開発者ツールを使えば誰でも回避できます。ふだん使っているパスワードは決して入力しないでください。

15. よくある質問

アイコンが英語の文字になっている

アイコン用のフォント（Google Material Icons）を読み込めていません。インターネットにつながっているか確認し、ページを再読み込みしてください。広告ブロッカーなどが原因のこともあります。

ウィンドウのボタン（– □ ×）が押せない

ページを強制再読み込みしてください（PC は Ctrl+F5、スマートフォンはブラウザのキャッシュ削除）。古い版が残っていることがあります。それでも直らないときは、端末とブラウザの名前を添えてご連絡ください。

パスワードを忘れた

残念ながらパスワードの再設定機能はありません。データを残す方法はありません。次のどちらかで初期化してください。
① ブラウザの設定でこのサイト（maitononaka.github.io）のサイトデータを削除する。
② ブラウザの開発者ツールのコンソールで localStorage.removeItem('jshell-gui-v1') を実行して再読み込みする。

ブルースクリーンが何度も出る／回復環境から抜けられない

回復環境で「詳細オプション → スタートアップ修復」を実行し、「再起動」を押してください。それでも直らなければ「システムの復元」、最後に「このPCを初期状態に戻す」を使います。

UEFI に入れない

起動画面が出ている間に Enter を素早く 3 回押します。間に合わないときは、スタートメニューの「UEFI ファームウェア設定」から入って Boot Delay を長くしてください。スマートフォンでは起動画面を素早く 3 回タップします。

ごみ箱を空にしたファイルを戻したい

完全に削除したものは戻せません。

スマートフォンで画面の上の方が押しにくい

ウィンドウは端末のステータスバーやノッチを避けて表示されます。ホーム画面に追加せずに通常のブラウザで開き、最新のバージョンで試してください。

バージョンを知りたい

シェルで ver と入力するか、設定アプリの「システム情報」を開いてください。現在は 2.0.0 です。

16. まだできないこと・今後の予定

  • Web ブラウザアプリ（iframe を使う予定です）
  • 複数ユーザーの切り替え
  • シェルのパイプ・リダイレクト・ワイルドカード、文字だけの JShell にある pkg や vi などの機能
  • 回復環境の「スタートアップ設定」「デバイスの使用」「更新プログラムのアンインストール」
  • Secure Boot の実際の効果（今は表示だけです）
